# API Documentation

The complete OpenAPI specification is auto-generated by FastAPI and available at `/docs` when the server is running. Below is a summary of the critical business routes.

## Authentication Routes
### `POST /api/v1/auth/login`
* **Purpose**: Issue JWT access and refresh tokens.
* **Auth**: None.
* **Body**: `OAuth2PasswordRequestForm` (username, password)
* **Response**: `{"access_token": "ey...", "token_type": "bearer"}`

## Biometrics & Attendance Routes
### `POST /api/v1/attendance/check-in`
* **Purpose**: The core loop. Accepts a live face frame and clocks the user in.
* **Auth**: Bearer Token required.
* **Body**: `{"image_base64": "/9j/4AAQSkZJRg..."}`
* **Response 200**: `{"message": "Check-in successful", "status": "On Time"}`
* **Response 400**: `{"detail": "Spoofing detected"}` or `{"detail": "Identity not recognized"}`

### `GET /api/v1/attendance/logs`
* **Purpose**: Fetch historical attendance records.
* **Auth**: Bearer Token required.
* **Query Params**: `skip`, `limit`, `start_date`, `end_date`

## SuperAdmin Routes
### `POST /api/v1/admin/settings/blockchain/toggle`
* **Purpose**: Dynamically enable or disable Ethereum smart contract anchoring.
* **Auth**: Bearer Token (MUST have `SuperAdmin` role).
* **Body**: `{"enabled": true}`
* **Response 200**: `{"message": "Web3 Integration Enabled"}`
